# ADR-0000: Template

- **Status**: proposed | accepted | superseded by [ADR-XXXX](XXXX-....md)
- **Date**: YYYY-MM-DD

## Context

The forces at play: the problem, the constraints, what was already true in the
codebase. No solutions here — a reader should be able to disagree with the
decision but not with the context.

## Decision

What was chosen, stated in one or two sentences, in the present tense
("The entity is a SwiftData `@Model`"). Point at the code that embodies it.

## Alternatives considered

Each one with the reason it lost. An ADR whose alternatives are strawmen is
worthless: list the options that were genuinely tempting.

## Consequences

What this buys, what it costs, and what it constrains later. Include the
escape hatch if there is one — how the decision would be undone.
